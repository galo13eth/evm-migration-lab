# Security policy

This repository is pre-release and has no mainnet deployment. Please report suspected vulnerabilities privately through [GitHub's security advisory form](https://github.com/galo13eth/evm-migration-lab/security/advisories/new). Do not include secrets, funded keys, or live user data in an issue.

Reports should include the affected commit, impact, reproduction steps, and any suggested mitigation. Expect acknowledgement within five business days. Public issues are appropriate for hardening ideas that do not disclose an exploitable vulnerability.

Only the latest tagged release is supported after `v0.1.0`; until then, `main` is the only supported line. This toolkit is a snapshot-and-claim reference, not a trustless bridge, and its documented operator/root-admin trust assumptions are not vulnerabilities by themselves.
